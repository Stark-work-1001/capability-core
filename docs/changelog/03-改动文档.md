# 03 · 改动文档

> 记录实现与本轮重构，按模块组织。

## 一、本轮重构（品牌与概念）

产品名统一为 **能力核心 / Capability Core**，术语全部回归使用场景。

| 项目 | 旧 | 新 |
| --- | --- | --- |
| 中文产品名 | （旧品牌） | 能力核心 |
| 英文产品名 | （旧品牌） | Capability Core |
| npm 包名 | — | `capability-core` / `capability-core-desktop` |
| 环境变量前缀 | （旧前缀） | `CC_` |
| 数据库文件 | （旧名） | `capability-core.db` |
| 资产目录 | （旧名） | `assets/` |
| 打包态数据目录 | （旧名） | `capability-core-data/` |
| MCP 工具前缀 | （旧前缀） | `capability.*` |
| 自有资产概念 | （旧隐喻） | 能力资产库 |
| 外部扫描索引概念 | — | 宿主能力库 |

**概念澄清**：确立「能力资产库 / 宿主能力库 / 能力数据库」三分，
并明确转化方向：宿主能力 ──「转为能力资产」──▶ 能力资产库 ──「生态同步」──▶ 各智能体配置。

## 二、工程骨架

- Electron 44 + React 19 + TypeScript + Vite 7 工程。
- 目录：`apps/desktop/src/{main,renderer}`、`tests`、`scripts`、`docs`、`assets`。
- 应用图标 `apps/desktop/build/icon.png`（脚本化生成）。

## 三、后端内核（`src/main`）

### core/

| 文件 | 内容 |
| --- | --- |
| `paths.js` | 数据目录解析（开发/打包多证据判定）、来源根目录表、路径越界保护、资产库归属判定 |
| `identity.js` | 产品身份常量（名称、App ID），避免多处硬编码 |
| `util.js` | id/哈希/稳定序列化/版本比较/中文令牌化/文件遍历/原子写入/目录复制 |
| `yaml.js` | 手写 YAML 子集解析器（块映射、块序列、行内数组对象、多行 `|`/`>`、注释、frontmatter 提取） |
| `toml.js` | 手写 TOML 解析器（表、数组表、行内数组、嵌套点键） |
| `manifest.js` | Capability Manifest v1：类型归一、身份键、指纹、检索文本 |
| `text-index.js` | CJK 逐字切分、FTS 查询构建、短语近似评分、snippet |
| `events.js` | 事件总线 + 持久化事件流 + 订阅广播 |
| `logger.js` | 分级日志、控制台 + 按日文件 |

### db/

- `schema.js`：业务表 + FTS5 虚表（unicode61）+ trigram 虚表 + 三个同步触发器。
  新增 `capabilities.scope` 列与 `model_providers` / `model_routes` / `model_calls` / `asset_vectors` 表。
- `db.js`：`Database` 封装（all/get/run/tx/backup/stats），WAL、busy_timeout、幂等迁移与 scope 回填。

### adapters/

- `skill.js`：SKILL.md 解析、资源清单、`hasFrontmatter`/`bodyChars` 事实记录。
- `mcp.js`：配置文件（JSON/YAML/TOML）三种键名兼容；工程目录识别（Node/Python/README）。
- `plugin.js`：DSH 插件（`dsh.bundle`/`dsh.client`）、Claude/Codex 插件、A2A Agent Card、OpenAPI。

### services/

| 文件 | 职责 |
| --- | --- |
| `context.js` | 组合根，装配全部服务 |
| `discovery.js` | 内置发现规则 + 来源落库 |
| `scanner.js` | 按来源类型分派扫描、增量写入、消失清理、故障信号 |
| `registry.js` | 能力 upsert（版本更高才覆盖主体字段）、安装实例、scope 归属、检索文档维护、统计 |
| `assets.js` | **新增**：能力资产库服务（创建/转化/删除/统计/磁盘同步） |
| `models.js` | **新增**：模型接入服务（提供商、角色路由、embedding/rerank/judge/chat、本地兜底、调用统计） |
| `search.js` | 多路融合检索、同义词扩展、解释性评分、浏览模式 |
| `dedupe.js` | 同名/相似检测、候选组落库、保留最新/合并/共存/忽略 |
| `faults.js` | 诊断规则、自动修复（备份+原子写）、派单工单、补丁校验回传 |
| `lifecycle.js` | 启停/隔离/固定/快照/删除（回收站）/恢复/导出/校验 |
| `imports.js` | 导入预检与入库（复制到 `assets/` 并登记来源） |
| `updates.js` | 上游缓存导入、目录查询、并发更新检查 |
| `ecosystem.js` | 宿主目标枚举、MCP 配置预览/写入、备份与回滚 |
| `agents.js` | 进程识别（WMI→tasklist 降级）、心跳扫描、MCP 会话、**连通检测与主动连通** |
| `workflows.js` | 内置工作流、步骤执行器、运行记录 |
| `seed.js` | 首次运行在资产库放置元技能，让中枢具备自我描述能力 |

### mcp/ 与 server/

- `mcp/server-core.js`：JSON-RPC 分发（initialize/ping/tools/resources/prompts）、
  13 个 `capability.*` 工具、会话与用量记录。
- `server/http.js`：REST 同源端点 + `/health` + `/mcp`，请求体大小限制。

### 桌面主进程

- `main.js`：窗口、托盘、40+ IPC 通道、后台调度（扫描/智能体/诊断）、截图验收通道。
- `preload.cjs`：白名单桥接，暴露 `window.capabilityCore`。

## 四、前端（`src/renderer`）

- `App.tsx`：侧栏三分组、14 个视图、事件订阅、全局跳转钩子。
- `lib/api.ts`：类型化桥接层，覆盖全部 IPC 通道。
- `components/ui.tsx`：徽章、Toast、Spinner 等基础件。
- 视图：总览、**能力资产库（新）**、宿主能力库、检索实验室、智能体接入（含连通按钮）、
  来源与扫描、去重裁决、维修站、更新管理、工作流、**模型接入（新）**、生态同步、数据库、设置。

## 五、工程与打包

- `scripts/build.mjs`：Vite 构建 → 组装备份目录 → 编译原生启动器 → 复制 Electron 运行时 →
  组装 `resources/app/` → 写启动器与版本文件 → 产物自检。
- `scripts/launcher.cs`：**新增**：原生启动器源码，在任何 JS 执行前清除
  `ELECTRON_RUN_AS_NODE` 并设置打包标记。
- `scripts/dev.mjs` / `scripts/start.mjs`：开发与启动脚本，均剔除干扰环境变量。
- 测试：6 个文件、35 个用例。

## 六、本轮修复的关键缺陷

| 缺陷 | 现象 | 修复 |
| --- | --- | --- |
| SQL 占位符多一个 | 新建/转化能力全部抛 `26 values for 25 columns` | 删除多余 `?`，并做全树 38 处 INSERT 三方比对 |
| 资产目录名 ≠ 数据库主键 | 磁盘目录无法反查记录 | id 只在最外层生成一次并向下传参 |
| 类型静默降级 | `agent` 能力被伪装成 `skill` | 返回 `kindCoerced/fromKind/toKind` 并在界面标注 |
| 重复转化不去重 | 同一能力重复转化产生多条记录 | 按 `metadata.promotedFrom` 查重，命中则复用 |
| 打包态判定依赖环境变量 | 双击 exe 数据写进应用包 | 改为三条物理证据判定 |
| `ELECTRON_RUN_AS_NODE` 秒退 | 双击 exe 静默退出、零日志 | 新增原生启动器，在 JS 执行前清环境 |
