## 协议支持边界

| 协议 | 本轮范围 | 尚未覆盖 |
|---|---|---|
| MCP stdio | initialize、ping、tools/list、tools/call、主动会话及用量 | 其他可选协议能力 |
| MCP Streamable HTTP | POST JSON、会话、通知、DELETE、版本检查 | 服务器主动 SSE、OAuth |
| Agent Skills | 元数据、正文、资源纳管 | 不代替宿主执行技能 |
| Claude / Codex Plugins | plugin.json、技能与 MCP 声明吸收 | hooks 与扩展运行时 |
| VS Code / Cursor | servers / mcpServers 配置 | 厂商所有私有扩展 |
| OpenAPI 3 | JSON 操作声明与输入可检索 | 自动执行远程业务操作、YAML |
| A2A | Agent Card 与技能声明导入 | A2A 任务执行传输 |
| ACP | 规格调研与前端说明 | 执行适配器 |

调研依据：[MCP 传输](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[Agent Skills 规范](https://agentskills.io/specification)、[Codex Plugins](https://developers.openai.com/plugins/build/plugins)、[Claude Plugins](https://code.claude.com/docs/en/plugins-reference)、[VS Code MCP](https://code.visualstudio.com/docs/agent-customization/mcp-servers)、[A2A](https://a2a-protocol.org/latest/specification/)、[ACP](https://agentclientprotocol.com/protocol/v1/overview)、[OpenAPI](https://spec.openapis.org/oas/latest.html)。协议清单明确显示部分支持，未将声明解析等同于完整执行协议。

## 验证与候选交付

内核 531 项测试、前端 150 项测试、隔离链路 46 项检查通过。链路报告位于 `artifacts/acceptance-20261019-final3/report.json`。模型相关链路使用本机模拟服务验证；真实云端模型的效果和账户连通性需在配置后验收。

桌面候选包只创建在开发目录 `artifacts/candidates/` 内，默认 18297 端口；日常 standalone 保持 18198，开发版保持 18197。候选标记、数据库、浏览器数据互相隔离，不携带密钥。

随包提供 Python 3.12.10 嵌入式运行时、WebView2 155.0.4283.62 官方固定运行时和 SHA-256 清单。当前机器从 D 盘运行固定运行时发生 GPU 子进程创建错误；将同一组官方文件部署到 C 盘本地缓存后可启动。因此程序采用离线校验与本地缓存部署，不需要在线安装运行时。缓存仅存放可重建的运行时文件，数据库仍留在各自程序目录。依据：[Microsoft 固定版本分发说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。

当前修订生成支持单个入口文件（技能正文、MCP JSON、插件/身份/组织清单）；多文件修复通过受控包导入完成。生成和静态校验通过不等于能力在真实宿主运行成功，发布后仍需巡检及实际调用验收。

未经用户审核，不运行带 `-ReviewedStandalone` 的发布脚本，不更新日常使用目录。

模型预填采用官方已列出的 [Qwen3-Embedding-8B](https://siliconflow.cn/news/w9z4gypmg1fulueqh18pkb7o)、[Qwen3.8-27B](https://www.siliconflow.cn/models) 和 [Qwen3-VL-Reranker-8B](https://docs.siliconflow.cn/docs/api/rerank-post)。其余专项槽位的模型名留空。默认禁用且不带密钥，用户填入凭据并启用、测试后才能完成真实云端验收。
